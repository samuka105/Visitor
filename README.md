# Padrão Visitor

Exemplo do padrão comportamental **Visitor** aplicado a um carrinho de compras com
itens de tipos diferentes (livro, eletrônico e assinatura). Duas operações distintas : gerar a nota fiscal e gerar a etiqueta de entrega, são implementadas como
visitantes separados, sem alterar as classes dos itens.

## Conteúdo do repositório

- **Código-fonte** do exemplo implementando o padrão Visitor (carrinho com dois visitantes).
- **Casos de teste** (JUnit) cobrindo os dois visitantes sobre cada tipo de item e a diferença de resultado entre eles.
- **Diagrama UML** das classes, em formato de imagem.
